# StoryEco | Kitsu Local Backup — v1.1.1

- استفاده پیش‌فرض از اعتماد استاندارد TLS؛ CA سفارشی اختیاری و بررسی گواهی همواره فعال است.
- مهاجرت یک‌باره تنظیم قدیمی گواهی همراه برای Endpoint قبلی، با حفظ CAهای سفارشی دیگر.
- تکمیل هر دو آرشیو سرور با پوشه واقعی Release فعال Kitsu، فهرست نسخه‌های Python و Hook تمدید گواهی.
- حذف گواهی تاریخی از بسته اجرایی جدید و افزودن تست‌های تنظیمات TLS.

## ارتقا

برنامه قبلی را ببندید و بسته جدید را کامل استخراج کنید. در تنظیمات، CA سفارشی اتصال استاندارد را خالی بگذارید و ذخیره کنید. سپس «نصب/آپدیت Helper»، «تست سرور» و «تست S3» را اجرا کنید و بکاپ تازه بگیرید.

بکاپ‌های قدیمی حذف یا تبدیل نمی‌شوند. Snapshot آرشیو قابل‌حمل است، نه تصویر کامل دیسک. بازیابی کامل روی سرور مستقل هنوز آزموده نشده است. فایل‌های بکاپ حاوی اطلاعات حساس‌اند؛ آن‌ها را روی فضای رمزنگاری‌شده نگه دارید.
