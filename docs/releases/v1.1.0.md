# StoryEco | Kitsu Local Backup v1.1.0

این نسخه پشتیبان‌گیری S3 را با ساختار واقعی Kitsu/Zou هماهنگ می‌کند.

## تغییرات اصلی

- شناسایی خودکار تمام Bucketهای قابل‌دسترسی با Credentialهای تنظیم‌شده
- دریافت جداگانه Bucketهای تصاویر، ویدئوها، فایل‌ها و سایر Bucketهای موجود
- نگهداری نام اصلی هر Bucket در ساختار بکاپ محلی برای بازیابی قابل‌انتقال
- تولید Inventory خلاصه و Inventory کامل جداگانه برای هر Bucket
- ساخت فایل `SUCCESS` تنها پس از موفقیت پشتیبان‌گیری همه Bucketها
- پشتیبانی امن از CA سفارشی با `rclone --ca-cert`
- همراه‌کردن گواهی عمومی Certum موردنیاز Endpoint فعلی، پس از کنترل اثرانگشت SHA-256
- مهاجرت خودکار تنظیمات Endpoint هاست ایران به Region واقعی `tehran-2`
- حفظ سازگاری با تنظیمات ذخیره‌شده نسخه ۱.۰
- حذف فیلد غیرضروری انتخاب Bucket از رابط کاربری
- به‌روزرسانی راهنمای فارسی بکاپ و بازیابی چند-Bucket

## ساختار خروجی S3

```text
S3\YYYY-MM-DD_HH-mm-ss\
├── data\<bucket-name>\
├── s3-inventory\<bucket-name>.json
├── s3-inventory.json
├── manifest.json
├── rclone.log
└── SUCCESS
```

## کنترل کیفیت

- کامپایل Release و Self-test فایل اجرایی موفق
- استخراج ZIP و Self-test مجدد نسخه بسته‌بندی‌شده موفق
- اعتبارسنجی SHA-256 فایل ZIP موفق
- آزمایش TLS واقعی Endpoint با CA همراه برنامه موفق
- آزمایش عملی کشف چهار Bucket و دریافت فایل واقعی S3 موفق
- بررسی Hash و محتوای Snapshot و Backup سرور موفق

برای ارتقا، ZIP را در یک پوشه جدید Extract و فایل `KitsuLocalBackup.exe` را اجرا کنید. تنظیمات و Credentialهای حفاظت‌شده قبلی به‌صورت خودکار خوانده می‌شوند.
